Meeting the Brief

This is my computer science leaving cert project.

-BR 1 Starting with Basic Requirement 1, I designed an embedded system using a BBC Micro:bit to act as a remote sensor station. It utilizes the microbit's built-in sensors for analogue input, measuring light level, and digital input to measure temperature and counting the fire risk value depending on them. The primary output is the live data stream displayed in the console. The system is fully automated. Every change shows on the console. Light level is increasing from the phone flashlight and temperature by the heat from the fan.

-BR 2 For Data Collection, I integrated a logging mechanism using the csv library. On every cycle of the loop, the script takes the decoded data from the microbit and uses the “with open” command to append it to a file named “LCCS.csv” which is included in the project’s folder. This creates a persistent environmental database including temperature, light, and the calculated fire risk.

-BR 3 To address a quick message about the fire risk, I programmed a secondary logic loop on the microbit. The variable “BR3_Sim_Result” acts as a real-time status update based on the calculated risk. The microbit provides immediate visual feedback: a skull icon for critical fire risk (>=6000), a sad face for high fire risk, straight face for medium fire risk and happy for low risk

-AR 1 Moving to the Advanced Requirements, I developed a wildfire risk model. My Python model calculates the risk using the formula: fire_risk = temperature*light level, rounded to one decimal point for precision.

-AR 2 In AR 2, I programmed two "What-If" scenarios to test the model's behavior under theoretical conditions without needing physical heat sources: Scenario 1: I simulated low temperature and weak light level to verify if the model stays in a low-risk state. Scenario 2: I simulated a high temperature with higher light. These simulations prove the model correctly adjusts predicted risk when key forest variables are modified.

-AR 3 And finally, AR3. The Adaptive System provides a sophisticated feedback mechanism. The script monitors the fire risk and triggers a virtual "ALERT!!!" if the value exceeds my threshold of 6000. To ensure stability and prevent repeated notifications, I implemented hysteresis logic using an alert_flag. This automated response ensures the system adapts its behavior based on the most recent environmental data.
